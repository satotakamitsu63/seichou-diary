プライバシーポリシー

じゅんひかDiary ／ 2026年9月18日

じゅんひかDiary(以下「本アプリ」)は、個人が自分の家族の記録を残すために作った非営利のアプリです。運営者は個人であり、連絡先は ragubiiiii@gmail.com です。利用者は運営者本人とその配偶者の2名に限られており、一般に公開して利用者を募ることはありません。

取得する情報

本アプリは、ログインのためのメールアドレスと、利用者が自分で書き込んだ日記の本文・日付、および利用者が自分で添付した写真と動画を取得します。これ以外の情報を利用者から集めることはありません。広告は表示せず、アクセス解析ツールも使用していません。

情報の利用目的

取得した情報は、日記を保存して利用者本人と配偶者が読み返せるようにするためだけに使います。他の目的には使いません。

保存場所

日記の本文と日付はSupabase(データベース)に保存します。写真と動画は運営者本人のGoogleドライブ内の専用フォルダに保存します。いずれも許可された2名のアカウントだけが読み書きできるよう制限しており、一般に公開される場所には置いていません。

Googleユーザーデータの取り扱い

本アプリがGoogleに求める権限は、Googleドライブのdrive.file(本アプリが作成したファイルのみを扱う権限)だけです。利用者のドライブにある他のファイルを読み取ることはできません。本アプリがGoogle APIから受け取った情報の使用と転送は、Google API Services User Data Policy(限定使用の要件を含む)に準拠します。

第三者への提供

取得した情報を第三者に販売・提供することはありません。保存のために利用しているSupabaseおよびGoogleの各サービスを除き、外部に送信することもありません。

削除

利用者はアプリの画面から、自分で書いた記録をいつでも削除できます。保存済みの情報をすべて削除したい場合は、上記の連絡先までご連絡ください。

本ポリシーの変更

内容を変更する場合は、このページを更新し、冒頭の日付を改めます。
